# artemidagroup.eu: notes for agents

Static multilingual site (PL root, /ru/, /en/) generated by a Python script, plus one Cloudflare Pages Function for the contact form. No framework, no npm dependencies.

## Layout

- `site/`: generated output that Cloudflare Pages serves. `pnpm build` copies it to `dist/`. Do not hand-edit; regenerate.
- `site-src/build.py`: generator (stdlib only). `python3 build.py` writes `site-src/dist`, `python3 build.py preview` writes `site-src/preview` with relative links.
- `site-src/content_{pl,ru,en}.py`: all page copy, titles, descriptions, FAQ. Same keys in every language.
- `site-src/legal.py`: privacy policy, cookie policy, terms (PL binding, RU/EN translations).
- `site-src/static/`: `site.css`, `site.js` (menu, consent banner with GA_ID/PIXEL_ID, form, moon phase), fonts (Roboto Flex subsets), favicon, `_headers`, `brand/logo.png`.
- `site-src/og.py`: renders OG images to `site-src/og/` (needs Playwright + Chrome). Re-run when a page's `og` title changes.
- `site-src/check.py`: SEO audit of `site-src/dist` (links, anchors, canonical, hreflang reciprocity, JSON-LD, title/description length, duplicates, sitemap). Must report 0 errors before publishing.
- `functions/api/applications.ts`: POST /api/applications, forwards to Telegram. Payload keys: type, name, email, website, service, messenger (E-mail/Telegram/WhatsApp/Viber), handle, message, language, pageUrl.

## Rules

- Polish URLs must stay stable (they rank). Routes live in `ROUTES` in `build.py`.
- After changing content: build, run check.py, copy `site-src/dist` to `site/`, commit.
- Keep copy free of invented facts: cases, prices and founder details come from the owner.
