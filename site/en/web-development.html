Common questions

How much does a website cost?

It depends on the scope: number of pages, language versions and integrations. After a short call we send a quote.

Will the website be ready for SEO?

Yes. We take care of speed, heading structure, structured data, the sitemap and correct language versions, so Google understands the site well.

Can you rebuild my existing website?

Yes. We start by reviewing the current site, and if page addresses change we set up redirects so you do not lose Google rankings.

Can you build a multilingual website?

Yes. Each language version gets its own address and is correctly marked up for search engines.
